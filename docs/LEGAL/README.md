# Юридические документы — черновики

Все документы в этой папке — **черновики, требуют проверки юристом** до публичного
запуска (дизайн‑док, 14.4: «Нужна консультация юриста перед запуском»).

| Файл | Что |
|---|---|
| `privacy-policy.md` | Политика конфиденциальности (показывается в приложении по адресу `/privacy`; исходник — `client/src/legal/privacy.md`) |
| `consent.md` | Согласие на обработку ПДн (онбординг, шаг 1) |
| `terms.md` | Пользовательское соглашение |

Отдельно юристу: уведомление Роскомнадзора об обработке ПДн, возрастная маркировка
информационной продукции, согласие несовершеннолетних 14–18 лет, условия Telegram для
Mini Apps.
