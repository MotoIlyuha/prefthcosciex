# Руководство методиста

Всё, что методист правит, — текстовые файлы в репозитории. Код трогать не нужно;
каждое изменение проверяется тестами, которые запускаются одной командой.

## Где что лежит

| Что | Файл | Формат |
|---|---|---|
| Формулировки условий (≥ 5 шаблонов на задание) | `egegen/egegen/config/templates/tNN.yaml` | YAML: подтипы и шаблоны с плейсхолдерами `{…}` |
| Карточки методов (бесплатная теория, шаблоны кода) | `egegen/egegen/config/cards/tNN.md` | Markdown: раздел `### <подтип>` или `### common` |
| Переключатели формата ФИПИ (10, 13, 23, 27) | `egegen/egegen/config/fipi_2027.yaml` | YAML |
| Награды, цены, порог, кэп, серия, ранги | `api/app/config/economy.yaml` | YAML с `season_id` |
| Этажи и обязательные этажи по диапазону | `api/app/config/floors.yaml` | YAML |
| Задания, баллы, шкала первичных → тестовых, «балл в час» | `api/app/config/curriculum.yaml` | YAML |
| Трек «Python‑минимум» | `egegen/egegen/pymin.py` | 8 уроков, генераторы упражнений |

## Шаблон условия

```yaml
templates:
  - id: t15_segments          # уникальный идентификатор
    subtype: "15.1_segments"  # к какому подтипу относится
    text: |
      На числовой прямой даны два отрезка: P = [{p1}; {p2}] ...
```

* Плейсхолдеры перечислены в комментарии над подтипом (`# плейсхолдеры: {p1} {p2} …`).
  Неизвестный или пропущенный плейсхолдер — ошибка теста, а не молчаливая опечатка.
* Markdown поддерживает `**жирный**`, `` `код` ``, списки, таблицы, блоки кода.
* Формулировки — собственные, без копирования текстов ФИПИ (14.4).
* У каждого задания должно быть не меньше 5 шаблонов (проверяется тестом).

## Карточка метода

Раздел `### <id подтипа>` — карточка этого подтипа; `### common` — общая для задания.
Первый блок ```` ```python ```` в карточке — это «Шаблон из карточки», который ученик
вставляет в редактор одной кнопкой, поэтому он должен быть рабочим и коротким.

## Проверка после правки

```bash
cd egegen
uv run egegen show 15 --seed 7 --difficulty 3         # как выглядит условие и разбор
uv run egegen gen 15 --seed 1 --n 200                 # 200 экземпляров: время, ответы, решатели
uv run egegen property-check 15                       # полный прогон по подтипам и сложностям
uv run pytest -q tests/test_config.py                 # шаблоны, плейсхолдеры, карточки
```

После пуша то же самое делает CI; стенд подхватывает изменения после деплоя.

## Экономика и сезоны

* Числа наград и цен меняются **только вместе с `season_id`** (5.6: цены неизменны
  внутри сезона). Админка откажет в правке цен без нового `season_id`.
* Перед сменой прогоните симуляцию трёх профилей: `cd api && uv run pytest -q
  tests/test_logic_economy.py` — она сверяет доход/расход за неделю с таблицей 5.4.
* Здоровье экономики на живых данных — админка → «Экономика» (цели 5.4 подсвечены).

## Переключение формата ФИПИ без выпуска клиента

`fipi_2027.yaml` (или админка → «Конфиг» → раздел `fipi`):

* `t10.answer_transform`: `octet_sum` | `address_no_dots` | `number`;
* `t23.graph_input_format`: `matrix_ods` | `edges_txt` | `figure`;
* `t27.answer_layout`: `one_line_pair` | `two_lines`;
* `approved: true` и новый `banner_ru`, когда демоверсия утверждена.

## Обратная связь от учеников

* «Что было сложным → Другое» — админка → «Прочее» → «Другое» для методиста,
  сгруппировано по подтипам.
* Тикеты «Сообщить об ошибке» — админка → «Тикеты»: условие, seed, версия генератора,
  эталон и ответы ученика. Подтверждённый тикет возвращает монеты + 20 🪙 и попадает в
  список регресса (`/api/admin/issues/regressions`) — этот seed добавляется в тесты.
* Новый подтип сначала 3 дня работает только в слоте «Вызов» (флаг `beta`).
