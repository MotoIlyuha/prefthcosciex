# Задание 8 · Комбинаторика

### common

**Базовый приём — перебор.** Пока слов не больше нескольких миллионов,
Python перебирает их быстрее, чем вы вспомните формулу.

```python
from itertools import product
alphabet = 'АЕИОУ'                                    # ← порядок из условия
cnt = 0
for w in product(alphabet, repeat=5):                 # ← длина слова
    s = ''.join(w)
    if s.count('А') <= 1 and 'ЕО' not in s:           # ← условия из условия задачи
        cnt += 1
print(cnt)
```

**Порядок работы.**

1. Выписать алфавит **в порядке из условия**.
2. Оформить условие отдельной строкой и проверить её на двух-трёх примерах
   («а это слово подходит? а это?»).
3. Посчитать.

**Ловушки.**

* «Не менее» / «не более» / «ровно» — три разных условия.
* «Буквы не повторяются» — это `permutations`, а не `product`.
* Порядок букв берётся из условия, а не из настоящего алфавита.
* 6 букв в слове из 6 символов — 46 656 слов, перебор мгновенный;
  10 букв из 6 — уже 60 миллионов, нужна формула.

### 8.2_word_number

Список слов, упорядоченный по алфавиту условия, — это просто числа в системе
счисления с основанием «размер алфавита», где цифра буквы равна её номеру
в этом алфавите. Номер слова = значение этого числа + 1.

```python
from itertools import product
words = sorted(''.join(w) for w in product('АЕИОУ', repeat=4))
print(words.index('ОУУУ') + 1)
```

### 8.3_distinct_letters

«Буквы не повторяются» — это принципиально другая конструкция: `permutations`,
а не `product`. Количество равно K·(K−1)·…·(K−L+1): первую букву выбираем
K способами, вторую — уже K−1, и так далее.

```python
from itertools import permutations
alphabet = 'АЕИОУ'
cnt = 0
for w in permutations(alphabet, 3):     # ← длина слова
    s = ''.join(w)
    if s[0] not in 'АЕ':                # ← дополнительные условия, если есть
        cnt += 1
print(cnt)
```

Проверьте себя формулой без условий: для 5 букв и длины 3 должно получиться
5 · 4 · 3 = 60. Если перебор даёт другое число — перепутан `product`
с `permutations`.

### 8.5_large

Перебор уже не успевает — работает правило умножения:

* никакие две одинаковые буквы не рядом: `K · (K−1)^(L−1)`;
* первая буква из набора S, остальные любые: `|S| · K^(L−1)`.

Проверьте формулу перебором на маленькой длине (L = 3 или 4) — если сходится,
можно смело применять к большой.
