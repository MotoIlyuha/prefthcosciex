# Задание 10 · Маска подсети

### common

> **Новое в 2027:** это задание переехало на 10‑е место с 13‑го, и изменился
> формат ответа — теперь записывают **сумму числовых значений октетов**
> найденного адреса. Для 100.20.3.4 ответ будет 100 + 20 + 3 + 4 = 127.

**Что нужно знать.**

* Маска — это 32 бита: сначала подряд идущие единицы, потом нули. Число единиц
  обычно обозначают k (запись «/24»).
* Адрес сети = адрес узла **&** маска (поразрядная конъюнкция).
* Чем больше единиц в маске, тем **меньше** сеть. «Наименьшее число адресов»
  значит «наибольшее k».
* Число узлов в сети = 2^(32−k) − 2, если из условия следует, что адрес сети
  и широковещательный адрес не считаются.

**Шаблон.**

```python
import ipaddress
ip1, ip2 = '192.168.13.70', '192.168.13.200'      # ← адреса из условия
for k in range(32, -1, -1):                        # от самой узкой сети к широкой
    net = ipaddress.ip_network(f'{ip1}/{k}', strict=False)
    if ipaddress.ip_address(ip2) in net:           # ← условие «в одной сети»
        a = net.network_address
        print(k, a, sum(map(int, str(a).split('.'))))
        break
```

**Ловушки.**

* Маска — это **только подряд идущие** единицы; 255.255.0.255 маской не является.
* «Ровно k единиц в двоичной записи адреса» считается по **всем 32 битам**,
  а не по последнему октету.
* Новый формат ответа легко забыть — над полем ввода в приложении подпись,
  читайте её.
