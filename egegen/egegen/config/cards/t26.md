# Задание 26 · Сортировка и жадные алгоритмы

### common

**Первая строка файла — параметры, а не данные.** Читайте её отдельно.

**Первое число ответа — жадность.** Чтобы взять как можно больше предметов,
берите самые маленькие: отсортируйте и набирайте, пока помещается.

```python
import bisect

f = open("26.txt")
n, S = map(int, f.readline().split())  # ← параметры
a = sorted(int(f.readline()) for _ in range(n))
total = cnt = 0
for x in a:
    if total + x <= S:
        total += x
        cnt += 1
    else:
        break
```

**Второе число — самое коварное место задания.** Обычно спрашивают
*наибольший предмет, который может оказаться в наборе из cnt штук*, а это
**не** последний взятый элемент. Уберите последний взятый, посмотрите,
сколько места освободилось, и найдите самый большой элемент, который туда
влезет:

```python
free = S - (total - a[cnt - 1])
j = bisect.bisect_right(a, free) - 1
print(cnt, max(a[cnt - 1], a[j]))
```

**Как себя проверить.** Возьмите те же 8 чисел и решите задачу руками
на бумаге. Если сходится — запускайте на полном файле.

**Ловушки.**

* Порядок двух ответов менять нельзя; за одно верное число дают 1 балл из 2.
* Равные элементы — обычное дело, `bisect_right` учитывает их правильно.
* O(n²) на 10⁵ элементах не успеет: нужны сортировка и `bisect`
  либо два указателя.
