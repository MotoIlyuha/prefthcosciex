# Задание 5 · Алгоритм над записью числа

### common

**Никогда не считайте это вручную.** Алгоритм из условия переписывается
на Python за минуту, и дальше остаётся перебор.

```python
for n in range(1, 10_000):
    s = bin(n)[2:]                                  # ← двоичная запись N
    s += '0' if sum(map(int, s)) % 2 == 0 else '1'  # ← шаги алгоритма
    s += s[-1]
    r = int(s, 2)
    if r > 100:                                     # ← условие из вопроса
        print(n, r)
        break                                       # ← для «наименьшего»
```

**Порядок действий.**

1. Записать шаги как функцию `f(n)`.
2. **Проверить функцию на примере из условия** — он там всегда есть.
   Если пример не сходится, вы неправильно прочитали шаг.
3. Перебрать N и вывести первое (или последнее) подходящее.

**Ловушки.**

* «Дописывается справа» и «дописывается слева» — разные шаги, читайте внимательно.
* «Чётность суммы цифр» — это не чётность самого числа.
* «Наименьшее N, большее …» — условие на **R**, а ответ — **N**. Их легко перепутать.
* Для «наибольшего N» нельзя ставить `break` — нужно пройти весь диапазон.

### 5.4_unreachable

Здесь перебирать нужно **варианты ответа**, а не N. Соберите множество всех
достижимых R (для N до 10 000) и посмотрите, какого из четырёх чисел в нём нет.

```python
reach = {f(n) for n in range(1, 10_000)}
for x in (100, 127, 150, 168):
    if x not in reach: print(x)
```

### 5.6_ternary

Троичная запись — своя функция перевода; `bin` здесь не поможет.

```python
def to3(n):
    s = ''
    while n: s = str(n % 3) + s; n //= 3
    return s or '0'
```

Обратный перевод — `int(s, 3)`.
