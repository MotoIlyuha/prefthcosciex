### common

**Сначала черновик, потом код.** Выпишите **все** фильтры из условия — их
обычно четыре: отдел, район, период, тип операции. Именно пропущенный фильтр,
а не арифметика, стоит балла.

**Метод — два словаря и один цикл.**

```python
import csv

product = {}  # артикул → (отдел, в упаковке, цена)
for a, name, dep, pack, price in list(csv.reader(open("3-products.csv")))[1:]:
    product[a] = (dep, int(pack), int(price))

shop = {}  # ID магазина → район
for sid, name, district in list(csv.reader(open("3-shops.csv")))[1:]:
    shop[sid] = district

total = 0
for day, art, sid, op, qty in list(csv.reader(open("3-movement.csv")))[1:]:
    dep, pack, price = product[art]
    if dep != "Бакалея":
        continue  # ← фильтр 1
    if shop[sid] != "Южный":
        continue  # ← фильтр 2
    if not ("2026-10-05" <= day <= "2026-10-18"):
        continue  # ← фильтр 3
    if op != "Продажа":
        continue  # ← фильтр 4
    total += int(qty)  # ← что суммируем
print(total)
```

Даты в формате ГГГГ-ММ-ДД сравниваются как строки — это удобно и надёжно.

**Ловушки.**

* **Упаковки ≠ штуки.** Количество в таблице движения — в штуках; если
  спрашивают упаковки, делите на «В упаковке» из справочника товаров.
* Период — **включительно** с обеих сторон.
* В одном районе бывает несколько магазинов — фильтруйте по району, а не по
  конкретному магазину.
* Товары с одинаковым названием могут иметь разные артикулы: связывайте
  по артикулу.
* «Поступление» и «Продажа» — разные операции; для разности нужны обе.

### 3.3_revenue

Цена в справочнике указана **за упаковку**. Поэтому порядок такой: штуки →
упаковки → умножить на цену. Умножить цену на штуки — типичная ошибка,
и число получится в разы больше.
