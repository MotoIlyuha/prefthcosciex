# Задание 7 · Объём графики и звука

### common

**Единственный надёжный приём — всё перевести в биты, а в нужные единицы
переводить один раз, в самом конце.**

* Изображение: `i = ⌈log₂ K⌉` бит на пиксель, `I = W · H · i` бит.
* Звук: `I = f · i · t · каналы` бит.
* Передача: `t = I / v`.

**Единицы.** В ЕГЭ приставки к байтам — степени двойки:
1 Кбайт = 2¹⁰ байт, 1 Мбайт = 2²⁰ байт, 1 Кбит/с = 2¹⁰ бит/с.
А вот **кГц — это ×1000**, а не ×1024: частота измеряется в обычных герцах.

**Python.**

```python
import math
W, H, K = 640, 480, 256
i = math.ceil(math.log2(K))
print(W * H * i // (8 * 1024))     # объём в Кбайт
```

**Ловушки.**

* Стерео — это ×2.
* Минуты нужно перевести в секунды.
* «Минимально возможное число бит на пиксель» — округление **вверх**.
* При поиске числа цветов из объёма ответ — `K = 2^i`, а не само `i`.
* «Во сколько раз» — считайте отношение, не считайте оба объёма целиком.
