# Задание 9 · Электронная таблица

### common

**Один приём закрывает почти все варианты: отсортируйте числа строки.**
После `a = sorted(...)` условия записываются в одну строку.

```python
import csv

cnt = 0
for row in list(csv.reader(open("9.csv")))[1:]:  # первая строка — заголовки
    a = sorted(map(int, row))
    if len(set(a)) == len(a) - 1 and a[0] + a[1] > a[-1]:  # ← условие
        cnt += 1
print(cnt)
```

**Готовые формулировки.**

| Условие в тексте | Как записать |
|---|---|
| все числа различны | `len(set(a)) == len(a)` |
| ровно одна пара повторов | `len(set(a)) == len(a) - 1` |
| сумма двух наименьших больше наибольшего | `a[0] + a[1] > a[-1]` |
| наибольшее больше среднего в k раз | `a[-1] * len(a) > k * sum(a)` |
| хотя бы m чисел делятся на d | `sum(x % d == 0 for x in a) >= m` |

**Ловушки.**

* «Повторяется ровно два раза» и «есть повторы» — разные условия.
* Среднее сравнивайте **через умножение**, а не через деление: дробная
  арифметика даёт ошибки округления, и одна-две строки теряются.
* «Количество строк» и «номер строки» — разные вопросы.
* Проверяйте условие на здравый смысл: после сортировки `a[0] + a[1] > a[-1] + a[-2]`
  не выполняется **никогда** (два наименьших не могут превзойти два наибольших).
  Если ваше условие даёт ноль строк — скорее всего, оно прочитано неверно.
* Первая строка файла — заголовки, её надо пропустить.

### 9.2_one_repeat

`len(set(a)) == len(a) - 1` означает ровно одну «лишнюю» копию — то есть одно
число встретилось дважды, остальные по разу. Если чисел три одинаковых, эта
проверка тоже даст `len(a) - 2`, так что условие отсеет такие строки само.

### 9.5_average

`среднее = sum(a) / len(a)`, поэтому «наибольшее больше среднего в k раз»
это `a[-1] > k * sum(a) / len(a)`, а без деления — `a[-1] * len(a) > k * sum(a)`.
Вторая запись точная.
