# Задание 14 · Системы счисления

### common

**Python считает точно.** Никаких приближённых вычислений: `3**150` — это
обычное целое число, ограничений на размер нет.

```python
def to_base(n, b):
    d = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ'; r = ''
    while n: r = d[n % b] + r; n //= b
    return r or '0'

print(to_base(3**150 + 5**40 - 17, 9).count('0'))   # ← выражение, основание, вопрос
```

Обратный перевод — `int('1A2', 16)` (понимает буквы до основания 36).

**Ловушки.**

* Ведущая цифра не может быть нулём.
* При основании больше 10 цифры записываются буквами: A = 10, B = 11, …
* «В системе с основанием 3» и «троичная запись двоичного числа» — разные вещи.
* Если неизвестная цифра встречается в двух числах — она **одна и та же**.

### 14.2_unknown_digit

`int('1x2', 7)` с буквой не работает: подставляйте цифру строкой.

```python
for x in range(7):
    n = int('4x25'.replace('x', str(x)), 7)
    if n % 6 == 0: print(x, n)
```

Если подходят несколько x, перечитайте условие: обычно спрашивают минимальное
значение или сумму всех подходящих.
