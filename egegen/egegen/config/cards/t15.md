# Задание 15 · Логика с параметром

### common

**«Тождественно истинна» = нет ни одного контрпримера.** Отсюда и метод:
перебрать кандидатов A, и для каждого проверить формулу **на всей области x**.

**Как записывать логику.**

* Импликация `P → Q` — это `(not P) or Q`.
* Дизъюнкция `∨` — `or`, конъюнкция `∧` — `and`, отрицание `¬` — `not`.
* В побитовых условиях обязательно ставьте скобки: `(x & A) == 0`.

**Четыре шаблона под четыре подтипа.**

```python
# 15.1 отрезки: наименьшая длина A
def seg(x, a, b):
    return a <= x <= b


best = None
xs = [i / 2 for i in range(0, 121)]  # шаг 0.5 — чтобы не пропустить границы
for i, a in enumerate(xs):
    for b in xs[i:]:
        if all((not (seg(x, 10, 40) and not seg(x, 22, 55))) or seg(x, a, b) for x in xs):
            if best is None or b - a < best:
                best = b - a
print(best)


# 15.2 ДЕЛ: наибольшее A
def DEL(x, a):
    return x % a == 0


print(
    max(
        A
        for A in range(1, 1000)
        if all((not DEL(x, 21)) or (not DEL(x, 35)) or DEL(x, A) for x in range(1, 5000))
    )
)


# 15.4 побитовые: наименьшее A
def bit(x, m):
    return (x & m) != 0


print(
    min(
        A
        for A in range(1, 1024)
        if all((not bit(x, 12)) or (not bit(x, 5)) or bit(x, A) for x in range(0, 1024))
    )
)
```

**Ловушки.**

* Сетка x должна покрывать **все** границы: для отрезков с целыми концами
  берите шаг 0,5, иначе потеряете случай «ровно на границе».
* `ДЕЛ(x, 1)` истинно всегда, поэтому A = 1 подходит формально — спрашивают
  **наибольшее** значение.
* Приоритет операций: `¬`, `∧`, `∨`, `→`. Когда в формуле есть и `∨`, и `→`,
  расставьте скобки на черновике.
* Множество A может быть пустым — проверьте и этот вариант.

### 15.2_del

Полезное наблюдение, которое экономит время: посылка `ДЕЛ(x, a) ∧ ДЕЛ(x, b)`
истинна ровно тогда, когда x делится на **НОК(a, b)**. Значит, A обязан быть
делителем НОК(a, b), и наибольшее подходящее A — это сам НОК. Перебором
получится то же самое — используйте его как проверку.

### 15.3_sets

Формула из двух частей читается так: первая требует, чтобы A **содержало**
пересечение P и Q, вторая — чтобы A **лежало внутри** R. Наименьшее по сумме
такое множество — само пересечение (если оно помещается в R).

### 15.4_bitwise

Формула нарушается на тех x, у которых есть общие биты и с a, и с b. Для
каждого такого x нужно, чтобы A имел с ним хотя бы один общий бит. Перебирайте
A по возрастанию — первое подходящее и есть ответ.
