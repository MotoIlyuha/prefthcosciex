# Задание 25 · Делители и маски

### common

**Делители — только до квадратного корня.**

```python
def divisors(n):
    ds = set()
    for d in range(1, int(n ** 0.5) + 1):
        if n % d == 0:
            ds.add(d); ds.add(n // d)     # сразу оба: d и n // d
    return sorted(ds)
```

Множество само уберёт дубликат у полного квадрата (`d == n // d`).

**Шаблон перебора по диапазону.**

```python
for n in range(120_000, 130_000):         # ← диапазон из условия
    ds = divisors(n)
    if len(ds) == 4:                       # ← условие
        print(n, ds[-2])                   # ← число и второй по величине делитель
```

**Самопроверка.** Пар в ответе обычно 1–8. Если получилось сто — условие
прочитано неверно (чаще всего перепутано «ровно k делителей» с «делится на k»).

**Ловушки.**

* «Делители, отличные от 1 и самого числа» — это `ds[1:-1]`, а не `ds`.
* Второе число в паре — то, что просят: частное, делитель или сумма.
  Прочитайте вопрос ещё раз перед выводом.
* Порядок вывода — по возрастанию самого числа.

### 25.2_mask_multiple

Перебирать все числа до 10⁷ не нужно и долго. Перебирайте **только кратные M**:

```python
from fnmatch import fnmatch
M = 1023
for x in range(M, 10**7 + 1, M):
    if fnmatch(str(x), '1?2*3'):
        print(x, x // M)
```

`fnmatch` понимает `?` (ровно один символ) и `*` (любое количество, в том числе
ноль). Не путайте: `*` может совпасть с пустой строкой.
