**Кратчайший путь — Дейкстра или Флойд–Уоршелл.**

```python
import csv, heapq

rows = list(csv.reader(open("23.csv")))
names = rows[0][1:]
g = {u: {} for u in names}
for r in rows[1:]:
    for v, w in zip(names, r[1:]):
        if w.strip() and int(w):
            g[r[0]][v] = int(w)


def dijkstra(g, s):
    d = {s: 0}
    pq = [(0, s)]
    while pq:
        du, u = heapq.heappop(pq)
        if du > d[u]:
            continue
        for v, w in g[u].items():
            if du + w < d.get(v, float("inf")):
                d[v] = du + w
                heapq.heappush(pq, (d[v], v))
    return d


print(dijkstra(g, "A")["K"])
```

Для графа из десятка вершин проще запомнить Флойда — три вложенных цикла:
`d[i][j] = min(d[i][j], d[i][k] + d[k][j])`.

**Число путей в ациклическом графе — рекурсия с кэшем.**

```python
from functools import lru_cache

dag = {"A": ["B", "C"], "B": ["D"], "C": ["B", "D"], "D": ["E"], "E": []}


@lru_cache(None)
def paths(u, t):
    return 1 if u == t else sum(paths(v, t) for v in dag[u])


print(paths("A", "E"))  # всего
print(paths("A", "B") * paths("B", "E"))  # через B
print(paths("A", "E") - paths("A", "B") * paths("B", "E"))  # минуя B
```

**На схеме то же самое делается в уме:** подпишите у каждой вершины число
путей из начальной, двигаясь слева направо. Число в вершине = сумма чисел
её предшественников.

**Ловушки.**

* Ориентированный граф и неориентированный — разные задачи. В матрице
  неориентированного графа значения симметричны, и в список смежности надо
  занести **оба** направления.
* Кратчайший путь считается **по весам**, а не по числу рёбер, если в условии
  не сказано иначе.
* «Минуя X» через вычитание корректно **только** для ациклического графа:
  там через X нельзя пройти дважды.
* Имена вершин — буквы, а индексы в файле — числа; не перепутайте.
* Если в графе есть цикл, «число путей» бесконечно — значит, условие
  прочитано неверно.

### 23.5_count_shortest

Считается не длина, а количество. В Дейкстре при релаксации: если найден
более короткий путь — количество копируется, если найден путь **той же**
длины — количества складываются.

### 23.6_longest_dag

Длиннейший путь в общем графе — трудная задача, но в ациклическом он
считается той же рекурсией с кэшем, только вместо суммы берётся максимум:
`longest(u) = 0, если u — конец, иначе 1 + max(longest(v))`.
