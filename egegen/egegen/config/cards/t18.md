# Задание 18 · Робот‑сборщик

### common

**Это динамическое программирование по таблице.**

> Значение клетки = монеты в ней **плюс** лучшее из значений тех клеток,
> откуда в неё можно прийти.

Робот ходит только в двух направлениях, поэтому приходов не больше двух:
слева и сверху (или слева и снизу, если он идёт вверх).

**Порядок работы.**

1. Посчитайте **без стен** — убедитесь, что файл прочитан правильно
   и первая клетка равна своему числу.
2. Добавьте стены: стена запрещает соответствующее направление прихода.
3. Максимум и минимум считайте в двух таблицах одновременно, одним проходом.

```python
import csv, json

g = [[int(c) for c in row] for row in csv.reader(open("18.csv"))]
walls = json.load(open("walls.json"))  # стена СПРАВА / СНИЗУ от клетки
R = {tuple(w) for w in walls["right"]}
D = {tuple(w) for w in walls["down"]}
n, m = len(g), len(g[0])
mx = [[None] * m for _ in range(n)]
mn = [[None] * m for _ in range(n)]
for i in range(n):
    for j in range(m):
        c = []
        if i > 0 and (i - 1, j) not in D:
            c.append((mx[i - 1][j], mn[i - 1][j]))  # сверху
        if j > 0 and (i, j - 1) not in R:
            c.append((mx[i][j - 1], mn[i][j - 1]))  # слева
        c = [t for t in c if t[0] is not None]
        mx[i][j] = g[i][j] + (max(t[0] for t in c) if c else 0)
        mn[i][j] = g[i][j] + (min(t[1] for t in c) if c else 0)
print(mx[-1][-1], mn[-1][-1])
```

**Ловушки.**

* Стены в `.ods` — это **границы ячеек**, на телефоне их не видно. В приложении
  они нарисованы жирными линиями и продублированы в `walls.json`.
* Направление движения задаётся условием: «вправо или вниз» и «вверх или
  вправо» — разные задачи.
* Стартовая клетка **считается**.
* Для минимума нельзя «обойти» дорогую клетку: разрешены только два
  направления, обходных путей не существует.
* Порядок ответа: сначала максимум, потом минимум (если условие не говорит
  иначе).

### 18.3_up_right

Робот стартует в **левой нижней** клетке и идёт вверх или вправо, финиш —
в правой верхней. Значит, строки нужно обходить снизу вверх, а приход
«снизу» — это клетка `(i+1, j)`, и стена между ними записана как `down`
у клетки `(i, j)`.

### 18.4_dense_walls

Когда стен много, часть клеток становится недостижимой. Их значение —
«нет пути», и его нельзя считать нулём: иначе минимум получится заниженным.
В коде выше это `None`, который отфильтровывается перед `max`/`min`.
