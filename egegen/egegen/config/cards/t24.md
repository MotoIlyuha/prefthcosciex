**Главный совет: сначала короткая строка.** Напишите руками 20–30 символов,
посчитайте ответ глазами и прогоните на ней программу. Почти все ошибки в этом

```python
s = open("24.txt").read().strip()  # strip() обязателен: в конце файла \n
```

**Базовые приёмы.**

```python
print(max(len(p) for p in s.split("X")))  # максимальная подстрока без символа X

best = cur = 1  # нет двух одинаковых подряд
for i in range(1, len(s)):
    cur = cur + 1 if s[i] != s[i - 1] else 1
    best = max(best, cur)
print(best)

lo = k = best = 0  # не более 3 символов Q — окно
for hi in range(len(s)):
    k += s[hi] == "Q"
    while k > 3:
        k -= s[lo] == "Q"
        lo += 1
    best = max(best, hi - lo + 1)
print(best)

import re  # ровно повторение «AB»

print(max((len(m) for m in re.findall(r"(?:AB)+", s)), default=0))
```

**Ловушки.**

* Перевод строки в конце файла — `strip()`.
* «Чередуются» означает «любые две **разные** соседние буквы», а не «ровно AB».
* Последний отрезок легко потерять: обновляйте максимум **на каждом шаге**,
  а не только когда счётчик сбрасывается.
* «Подстрока» — это непрерывный фрагмент, а не подпоследовательность.

### 24.3_window_k

Скользящее окно с двумя указателями. Правый идёт вперёд всегда, левый
подтягивается, пока условие нарушено. Каждый символ обрабатывается не более
двух раз — это O(n), на миллионе символов работает мгновенно.

### 24.6_no_three_repeat

символа, а с двух последних (они уже образуют допустимую пару).
