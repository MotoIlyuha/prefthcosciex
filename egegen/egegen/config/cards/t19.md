# Задание 19 · Игра: анализ алгоритма

### common

**Одна программа на три задания.** Все игровые задания решаются шаблоном
W1 / L1 / W2 / L2; меняются только ходы, условие окончания и печатаемый предикат.

```python
from functools import lru_cache

N = 129  # ← игра кончается, когда камней >= N


def moves(s):
    return [s + 1, s * 2]  # ← ходы из условия


@lru_cache(None)
def W1(s):
    return any(m >= N for m in moves(s))  # выигрыш за 1 ход


@lru_cache(None)
def L1(s):
    return not W1(s) and all(W1(m) for m in moves(s))


@lru_cache(None)
def W2(s):
    return not W1(s) and any(L1(m) for m in moves(s))


@lru_cache(None)
def L2(s):
    return not W1(s) and not L1(s) and all(W1(m) or W2(m) for m in moves(s))


print([s for s in range(1, N) if L1(s)])  # ← 19: минимум
print([s for s in range(1, N) if W2(s)])  # ← 20: два значения
print([s for s in range(1, N) if L2(s)])  # ← 21: минимум
```

**Самопроверка.** Для N = 129 и ходов «+1, ×2» шаблон даёт
19 → 64; 20 → 32 и 63; 21 → 62. Если у вас другое — ошибка в `moves` или в `N`.

**Как читать условие — по словам.**

| Фраза | Предикат |
|---|---|
| «выигрывает своим первым ходом при любом ходе противника» | L1 |
| «не может выиграть первым ходом, но выигрывает вторым» | W2 |
| «выигрывает первым или вторым, но не гарантированно первым» | L2 |

**Ловушки.**

* `W2` обязательно требует `not W1`, иначе в ответ попадут лишние позиции.
* `L2` требует и `not W1`, и `not L1`.
* «Выигрывает тот, после чьего хода камней стало ≥ N» — читайте, кто именно
  выигрывает; в некоторых вариантах — наоборот, проигрывает.
* Для двух куч условие окончания — по **сумме**, а `moves` возвращает четыре
  позиции.
* В убывающих играх ходы могут вывести за границу — их надо отфильтровать.

### g3_two_piles

Известную кучу фиксируем, перебираем неизвестную: состояние — пара `(a, b)`,
`moves` возвращает четыре позиции, а в ответ идёт размер **второй** кучи.

### g6_decreasing

Здесь камни убирают, игра кончается на нуле, и выигрывает тот, кто забрал
последние камни. Ходы, уводящие в минус, надо отбросить:
`[s - k for k in (1, 2) if s - k >= 0]`.
