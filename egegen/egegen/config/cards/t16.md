# Задание 16 · Рекуррентные выражения

### common

**Переписать определение один в один — и всё.** Не упрощайте его алгебраически:
именно там теряются баллы.

```python
import sys; sys.setrecursionlimit(100_000)
from functools import lru_cache

@lru_cache(None)
def F(n):
    if n <= 1: return 1                 # ← база из условия
    return F(n - 1) + 2 * n             # ← шаг из условия

print(F(2027))
```

**Два обязательных штриха.**

* `@lru_cache(None)` — без него ветвящаяся рекурсия (`F(n−1) + F(n−2)`) зависнет.
* `sys.setrecursionlimit(100_000)` — без него глубина больше 1000 даст ошибку.

**Важно: у рекурсии есть потолок, который `setrecursionlimit` не поднимает.**
Если цепочка идёт от `n − 1` и n — несколько тысяч (а F(2027) — это ровно такой
случай), функция с `@lru_cache` падает с `RecursionError` примерно на глубине
3300. Это ограничение самого интерпретатора, и в браузерном Python (Pyodide)
оно точно такое же. Два надёжных выхода:

```python
def F(n):                       # снизу вверх — работает для любого n
    value = 1                   # ← база
    for k in range(2, n + 1):
        value = value + 2 * k   # ← шаг
    return value
```

```python
memo = {}                       # или обычный словарь вместо lru_cache
def F(n):
    if n <= 1: return 1
    if n not in memo: memo[n] = F(n - 1) + 2 * n
    return memo[n]
```

Рекурсия с `@lru_cache` остаётся лучшим выбором там, где глубина мала:
`F(n // 2)` (около log₂ n шагов), `F(n−1) + F(n−2)` и функции двух аргументов.

Для «F(2027) − F(2025)» просто посчитайте оба значения: Python не боится
больших чисел.

**Ловушки.**

* `n > 1` и `n ≥ 1` — разные базы, перечитайте.
* Если зависимость идёт от `n // 2`, цепочка короткая (≈ log₂ n шагов) —
  рекурсия отработает мгновенно даже для n = 100 000.
* В функции двух аргументов кэшируется **пара** аргументов.

### 16.4_call_count

Здесь спрашивают **количество вызовов**, а не значение. Кэшировать значения
нельзя — часть вызовов «исчезнет» и ответ будет занижен. Кэшируйте само
количество:

```python
@lru_cache(None)
def calls(n):
    if n <= 1: return 1
    return 1 + calls(n - 1) + calls(n - 2)
```

Единица — это текущий вызов, слагаемые — вложенные.
