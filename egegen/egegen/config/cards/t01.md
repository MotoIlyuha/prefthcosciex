# Задание 1 · Граф и таблица

### common

**Что спрашивают.** На схеме видно, какие пункты соединены. В таблице те же
дороги, но с длинами и без названий пунктов. Нужно сопоставить одно с другим.

**Метод — «степень и соседи».**

1. Возле каждой вершины **схемы** напишите её степень (сколько линий выходит)
   и в скобках отсортированные степени соседей: `3(2,3,4)`.
2. То же самое для каждой **строки таблицы**: степень — это число заполненных
   ячеек в строке.
3. Начните с вершин, у которых степень уникальна: такая вершина сопоставляется
   однозначно. Через неё определяются её соседи.
4. Когда соответствие найдено, прочитайте ответ прямо из таблицы.

**Ловушки.**

* Расположение вершин на рисунке ничего не значит — важны только связи.
* В таблице могут быть две вершины одинаковой степени: тогда решают соседи.
* Путь из A в B и из B в A — это одна дорога (таблица симметрична).
* Для «кратчайшего пути» нужно проверить **все** маршруты, а не первый найденный.

### 1.3_shortest_path

Здесь прямой дороги между нужными пунктами нет. После сопоставления выпишите все
маршруты между ними и сложите длины участков; ответ — минимальная сумма.
На 6–8 вершинах маршрутов немного, но их легко недосчитать — идите по соседям
системно.

### 1.4_vertex_number

Ответ — не длина, а **номер строки**. Если получилось несколько подходящих
строк, значит сопоставление ещё не однозначно: уточните его по степеням соседей.

### 1.5_symmetric

Степеней здесь недостаточно: есть несколько вершин с одинаковым числом связей.
Выписывайте для каждой вершины отсортированный список степеней её соседей —
эта «подпись» почти всегда различает вершины.
