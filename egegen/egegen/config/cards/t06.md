# Задание 6 · Исполнитель Черепаха

### common

**Три факта, без которых задача не решается.**

1. Черепаха стартует в начале координат и смотрит **вверх**.
2. «Направо m» — поворот **по часовой стрелке** (в математике это минус m градусов).
3. «Повтори k [ … ]» повторяет блок k раз; вершины при этом те же, фигура просто
   обводится несколько раз.

**Для прямоугольника считать перебором не нужно.** Если получился прямоугольник
w × h, то:

* строго внутри — `(w − 1)(h − 1)` точек;
* внутри или на границе — `(w + 1)(h + 1)` точек.

**Для остальных фигур — перебор по ограничивающему прямоугольнику.**

```python
from math import cos, sin, radians


def polygon(cmds, start=(0.0, 0.0)):
    x, y = start
    ang = 90.0
    pts = [start]  # старт: вверх
    for d, turn in cmds:  # направо — минус
        x += d * cos(radians(ang))
        y += d * sin(radians(ang))
        pts.append((round(x, 9), round(y, 9)))
        ang += turn
    return pts[:-1]


def inside(px, py, poly, strict, eps=1e-9):
    ins = False
    n = len(poly)
    for i in range(n):
        (x1, y1), (x2, y2) = poly[i], poly[(i + 1) % n]
        on = (
            abs((x2 - x1) * (py - y1) - (y2 - y1) * (px - x1)) < eps
            and min(x1, x2) - eps <= px <= max(x1, x2) + eps
            and min(y1, y2) - eps <= py <= max(y1, y2) + eps
        )
        if on:
            return not strict  # точка на границе
        if (y1 > py) != (y2 > py) and px < x1 + (py - y1) * (x2 - x1) / (y2 - y1):
            ins = not ins
    return ins


poly = polygon([(12, -90), (8, -90)] * 2)  # ← Повтори 2 [Вперёд 12 Направо 90 Вперёд 8 Направо 90]
xs = [p[0] for p in poly]
ys = [p[1] for p in poly]
print(
    sum(
        inside(x, y, poly, strict=True)
        for x in range(int(min(xs)) - 1, int(max(xs)) + 2)
        for y in range(int(min(ys)) - 1, int(max(ys)) + 2)
    )
)
```

**Ловушки.**

* «Внутри» и «внутри или на границе» — разные ответы, читайте это слово.
* Налево и направо легко перепутать, особенно когда в программе есть оба.
* У наклонных сторон вершины бывают иррациональными — считайте численно
  с допуском, не округляйте координаты.

### 6.3_intersection

«Поднять хвост» — перемещение без рисования. Вторая фигура начинается
в новой точке, и её координаты надо учитывать со смещением. Точка входит
в ответ, только если она принадлежит **обеим** фигурам:
`inside(x, y, poly1) and inside(x, y, poly2)`.
