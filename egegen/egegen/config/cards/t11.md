# Задание 11 · Информационный объём сообщения

### common

**Формула.**

1. `i = ⌈log₂ K⌉` — бит на один символ.
2. `L · i` — бит на один пароль.
3. `⌈L · i / 8⌉` — байт на **один** пароль (округляем каждый пароль отдельно).
4. `N · (байт + дополнительные)` — всего.

```python
import math

K, L, N, extra = 33, 8, 20, 4  # ← алфавит, длина, число записей, доп. байты
i = math.ceil(math.log2(K))
per = math.ceil(L * i / 8) + extra
print(N * per)  # в байтах
```

**Размеры популярных алфавитов:** 10 цифр, 26 строчных латинских,
52 латинских с регистром, 62 с цифрами, 33 русских (без «ё» — 32).

**Ловушки.**

* Округление вверх происходит **дважды**: сначала биты на символ, затем байты
  на пароль. Пропуск второго — самая частая ошибка.
* 1 Кбайт = 1024 байт, а не 1000.
* «Дополнительные сведения» обычно даются **на каждую запись**, а не на всю базу —
  перечитайте эту строчку условия.
* Если в идентификаторе символы двух видов, биты для каждой части считаются
  отдельно, а в байты округляется весь идентификатор целиком.
