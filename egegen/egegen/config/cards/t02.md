# Задание 2 · Таблица истинности

### common

**Идея.** Функция известна, а подписи столбцов потеряны. Значит: соберём все
наборы переменных, на которых функция даёт нужное значение, и посмотрим, какая
расстановка столбцов согласует эти наборы со строками таблицы.

**Обозначения в Python.**

| В условии | В Python |
|---|---|
| `¬x` | `not x` |
| `x ∧ y` | `x and y` |
| `x ∨ y` | `x or y` |
| `x → y` | `x <= y` |
| `x ≡ y` | `x == y` |
| `x ⊕ y` | `x != y` |

Приоритет: `¬`, `∧`, `∨`, `→`, `≡`.

**Шаблон.**

```python
from itertools import product, permutations
def F(x, y, z, w):                      # ← своя функция
    return ((x <= y) or (z == w)) and (not x or w)
rows = [(0, None, 1, 0), (1, 0, None, 1)]   # ← строки, None — пустая ячейка
val = 0                                      # ← значение F в этих строках
sets = [s for s in product([0, 1], repeat=4) if F(*s) == val]
for p in permutations(range(4)):
    for chosen in permutations(sets, len(rows)):
        if all(all(r[j] is None or r[j] == s[p[j]] for j in range(4))
               for r, s in zip(rows, chosen)):
            print(''.join('xyzw'[i] for i in p)); break
```

Если печатается больше одного варианта — функция записана с ошибкой.

**Ловушки.**

* Строки таблицы различны: одна строка не может соответствовать двум наборам,
  и два разных набора нельзя «повесить» на одну строку.
* Пустая ячейка означает «любое значение», а не ноль.
* `x → y` ложно **только** при `x = 1, y = 0`.
* При трёх переменных перестановок шесть, а не двадцать четыре.
