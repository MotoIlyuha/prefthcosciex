### common

**Главное правило: моделируйте буквально.** Две ошибки решают судьбу задачи.

1. `заменить (v, w)` меняет **только первое** вхождение. В Python это
   `s.replace(v, w, 1)`. Без третьего аргумента заменятся **все** вхождения —
   это не «стиль», это неправильный ответ.
2. Команды `ЕСЛИ` внутри цикла идут **последовательно**. Это `if`, `if`, `if` —
   не `if / elif / elif`. За один проход цикла может сработать несколько правил.

```python
s = '1' + '2' * 70 + '3' * 20            # ← исходная строка
while '12' in s or '23' in s:            # ← условие ПОКА
    if '12' in s: s = s.replace('12', '21', 1)
    if '23' in s: s = s.replace('23', '32', 1)
print(sum(map(int, s)))                  # ← сумма цифр / len(s) / s.count('1')
```

**Ловушки.**

* Порядок правил важен: поменяете местами — получите другой ответ.
* Бесконечный цикл — поставьте счётчик итераций с лимитом и проверьте условие.
* «Сумма цифр» — это `sum(map(int, s))`, а не сумма чисел в строке.

и сравнивайте результат с заданным.

```python
for n in range(1, 100):
    s = '1' * n + '2' * n

    if len(s) == 45: print(n)
```

### 12.5_long_string

для маленьких длин блоков (N = 5, 6, 7, …, 15), выпишите ответы столбиком
и найдите закономерность — почти всегда это линейная зависимость или период.
