# Байт — Telegram Mini App для подготовки к ЕГЭ‑2027 по информатике

Ежедневная 15‑минутная привычка вместо «прорешивания вариантов»: процедурно
генерируемые задания по всем 27 номерам КИМ, монеты с дневным порогом и кэпом,
серия дней, карта из 13 этажей, шкала уверенности по каждому заданию, режим
«Экзамен» в стиле КЕГЭ и куратор (родитель или репетитор).

Продуктовый источник правды — `docs/DESIGN-DOC.md` (дизайн‑док v1.0).

## Из чего состоит

| Каталог | Что это |
|---|---|
| `egegen/` | 27 генераторов заданий, два решателя на каждый, чекеры, property‑ и golden‑тесты, конфиги методиста (YAML/Markdown) |
| `api/` | FastAPI: авторизация, дейлики, экономика, навыки, этажи, магазин, куратор, экзамен, уведомления, админка, события |
| `client/` | Mini App и веб‑версия: React 18 + TypeScript + Vite, Pyodide, CodeMirror 6 |
| `bot/` | aiogram 3: `/start`, deep‑link'и, уведомления, одноразовые ссылки для веб‑версии |
| `worker/` | ARQ: планировщик дейликов в 05:00 по поясам, перепроверка кода, тяжёлые файлы задания 27, рассылки, отчёты |
| `runner/` | Изолированный раннер кода на nsjail: без сети, лимиты CPU/RAM/времени |
| `infra/` | Caddy, compose, деплой, бэкапы |
| `docs/` | Архитектура, API, руководство методиста, RUNBOOK, решения, известные пробелы, юридические черновики |

## Быстрый старт

```bash
cp .env.example .env          # заполнить TELEGRAM_BOT_TOKEN и остальное
make up                       # postgres, redis, minio, api, bot, worker, runner, client, caddy
make migrate && make seed     # схема БД и сиды (этажи, цены, карточки методов)
open http://localhost:8080
```

Полезное:

```bash
make test        # egegen (property + golden), api (pytest + PostgreSQL), client (vitest)
make lint        # ruff, mypy --strict, eslint, tsc --noEmit
make e2e         # Playwright: онбординг → дейлик → монеты → этаж → экзамен → куратор
make load        # k6: 500 одновременных пользователей
```

Один генератор вручную:

```bash
cd egegen
uv run egegen gen 17 --seed 42 --n 200          # 200 экземпляров, проверка времени и ответов
uv run egegen show 19 --seed 129 --difficulty 3 # условие, ответ, разбор
uv run egegen selfcheck                          # golden‑значения из дизайн‑дока
```

Все задания — собственная генерация. Из материалов ФИПИ используются структура и
типы заданий, не охраняемые формулировки (дизайн‑док, 14.4).
